WinResizer

윈리사이저는 macOS 창의 크기와 위치를 글로벌 단축키로 조절하는 가볍고 강력한 트레이 앱입니다. 극강의 응답성과 단일 바이너리 배포 단순화를 달성했습니다. WinResizer is a lightweight and powerful menu bar application that lets you snap and organize windows on macOS via global hotkeys. Built for peak responsiveness and simple deployment.

주요 특징 Core Features

가볍고 신속한 네이티브 동작을 한 번에 경험하세요. Experience fast, seamless native performance with no extra footprint.

글로벌 단축키 조절 Global Hotkeys

단축키 하나로 활성화된 창을 즉시 화면의 절반, 1/3, 2/3, 사분면 등으로 칼같이 배치합니다. Instantly snap active windows to half, 1/3, 2/3, or corner quadrants with straightforward shortcuts.

스마트 사이클링 Smart Cycling

동일한 단축키를 연속해서 누르면 미리 정의된 화면 분할 비율로 즉시 순환 조절됩니다. (예: 1/2 → 2/3 → 1/3) Pressing the same hotkey consecutively cycles the window size through predefined ratios (e.g., 1/2 → 2/3 → 1/3).

사이즈 리사이클 Size Recycling

단축키 반복 입력 시 창 폭을 10%씩 증감 조절하며, 20%에서 90% 한계를 넘으면 랩어라운드로 순환 조절을 지속합니다. Repeated presses expand or shrink window widths by 10%, wrapping around smoothly between 20% and 90% boundaries.

커스텀 비율 조절 Custom Ratios

웹 기반 설정 UI에서 상/하/좌/우 방향별 원하는 비율(1% ~ 100%)을 직접 섬세하게 지정하여 커스텀 단축키를 등록할 수 있습니다. Fine-tune width/height percentages (1% - 100%) for custom edges and bind your own shortcuts in the sleek web-based settings UI.

멀티모니터 완전 지원 Multi-Monitor Support

창이 현재 속해있는 모니터를 자동으로 똑똑하게 스캔하여, 해당 디스플레이 영역을 기준으로 정확하게 동작합니다. Automatically identifies which monitor the target window resides on and positions it precisely based on that display.

단일 바이너리 가벼움 Single Binary Efficiency

CGo를 통해 macOS 네이티브 API(Carbon, Accessibility)를 다이렉트로 호출하며, 다른 런타임 없이 15-25MB 수준의 가볍고 민첩한 네이티브 프로세스로 동작합니다. Directly calls native macOS APIs (Carbon, Accessibility) via CGo. Operates as a highly optimized, single binary (15-25 MB) with no heavy runtime.

설치 즉시 사용해볼 수 있는 직관적인 기본 단축키 세트입니다. A set of clean, intuitive global hotkeys pre-configured out of the box.

빠른 시작 (Quick Start) Quick Build & Start

터미널에서 직접 빌드하고 실행하거나 릴리즈 페이지에서 편리하게 받아보세요. Build and run the app manually using terminal or grab the pre-compiled DMG. 

# 1. 소스코드 복사# 1. Clone the repository
git clone https://github.com/danielk0121/winresizer-go.git
cd winresizer-go/app

# 2. 의존성 설치 및 빌드# 2. Install dependencies & build
go build -o winresizer .

# 3. 실행# 3. Run
./winresizer

필수 권한 설정 (macOS 2단계) Required Permissions (macOS 2-Step)

타사 앱 제어 및 시스템 단축키 입력을 조작하기 위해 최초 실행 시 아래 두 가지 손쉬운 권한 허용이 필요합니다. To seamlessly listen to keyboard shortcuts and position application windows, granting these two system-level permissions is required.

1단계: 손쉬운 사용 (Accessibility) Step 1: Accessibility

활성화된 다른 앱들의 창 좌표와 크기를 제어하기 위해 권한 승인이 요구됩니다.
경로: 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용 > winresizer 허용 Allows WinResizer to adjust window coordinate values.
Path: System Settings > Privacy & Security > Accessibility > Allow winresizer

2단계: 입력 모니터링 (Input Monitoring) Step 2: Input Monitoring

앱이 백그라운드에 위치해도 글로벌 지정 단축키를 놓치지 않고 감지하기 위해 요구됩니다.
경로: 시스템 설정 > 개인정보 보호 및 보안 > 입력 모니터링 > winresizer 허용 Allows background detection of your configured global hotkeys.
Path: System Settings > Privacy & Security > Input Monitoring > Allow winresizer
