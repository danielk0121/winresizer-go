## 개요
- 깃허브 주소 : https://github.com/danielk0121/winresizer-go
- 홈페이지 주소 : https://danielk0121.github.io/winresizer-go/homepage/
- github pages 기능 이용
- 아이콘 파일 경로 : /homepage/assets/icon_128x128.png
- index 파일 경로 : /homepage/index.html
- 리드미에 있는 내용 (기능설명, 스크린샷 등)을 참고해서 작성
- 깃허브 링크, 릴리즈 다운로드 링크 반드시 기재
- 검색엔진 검색 되도록 설정
- sns og 태그 설명 추가

## 부가 기능
- 홈페이지 영어, 한국어 다국어 설정 지원
- HTML, CSS, JavaScript를 각각 분리한 파일로 구성. i18n 라이브러리 지원은 필요 없으며, 한국어·영어 전환 기능만 제공.
- 가로 340px 모바일 환경에서도 CSS 레이아웃이 깨지지 않도록 반응형 스타일을 보완. 특히 버튼의 문구가 글자 단위로 세로 줄바꿈되지 않고 자연스럽게 한 줄 또는 단어 단위로 표시되도록 수정.
